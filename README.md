# friends仓库介绍

本仓库用于博客友链的记录,思路主要借鉴自[Candinya](https://github.com/Candinya)大佬的[仓库](https://github.com/kratos-rebirth/awesome)。


# 如何加入?

1. fork本仓库
2. 将站点图片上传至***images***目录
3. 在linklist.yml添加您个人站点的信息(格式如下)

   ```yaml
   - title: "站点名称" #请保留title前面的减号
     description: "站点的一句话描述"
     image: "站点的图片（或者可以是自己的头像）"
     link: "站点的地址"
   ```
4. 保存，提交，向上游开启一个 Pull request 。

注意，网站格式可按照仓库已有格式进行仿写 (再次感谢Candinya大佬,点击[Kratos : Rebirth 实例列表](https://awesome.krt.moe/show-my-site/), 对照仿写即可)
